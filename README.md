# SeforimOpenSiddur

Powered by the technologies that drive Zayit — https://zayitapp.com/

מנוע פתוח לסידור החכם של זיתא. המנוע בונה רצף תפילות ליום האזרחי וללילה שאחריו לפי הנוסח, לוח השנה, המיקום והבחירות. היישום מספק את הטקסט ואת כותרות תוכן העניינים ממסד הספרים דרך `SiddurSource`. המנוע עצמו אינו זקוק למסד SQLite, לחיבור רשת או לחבילת הסידור הפרטית של זית.

## מקורות וכללים

- הנוסחים הם סידור אשכנז, סידור ספרד וסידור נוסח עדות המזרח. ראש השנה ויום כיפור משתמשים גם במחזורים המתאימים שבמסד.
- `CorpusSections.kt` ממפה תפילות לכותרות במקורות. `SiddurCalendar.kt` משתמש ב־KosherKotlin לחישובי לוח. `CorpusAnnotations.kt` מתייג קטעים לפי הוראות מפורשות בתוך הטקסט.
- תנאי פסקאות נוספים מקורם ב־[Amud](https://github.com/Nt-f/amud/tree/c4327ead786ae15a1a80c946ebc2e34b5a345399/corpus). המחולל בוחר רק התאמות ייחודיות שבהן כל חלקי הפסקה קיבלו אותו תנאי נתמך. הקובץ שנוצר כולל טביעות SHA-256 ותנאים. טקסט התפילות מגיע מהספרייה של המשתמש.

## הרצה

נדרש JDK 25. לבדיקת המנוע יש להריץ `./gradlew jvmTest`, או `gradlew.bat jvmTest` ב־Windows.

אפשר לרענן את התיוגים מתוך העותק של Amud ומסד הספרים:

```sh
python tools/import_amud_annotations.py /path/to/amud /path/to/seforim.db
```

## כיסוי

המנוע הוא שחזור עצמאי מהקוד הפתוח של מסך זית, מהספרייה ומהתיוגים של Amud. הכיסוי תלוי במהדורות המותקנות ובכללים שמופו להן. צירופי מועדים ומנהגים, קריאות מיוחדות והפטרות, והוראות שמערבות כמה חלופות באותה פסקה עדיין מכוסים חלקית. לא בוצעה השוואה מלאה מול התוצר של מנוע זית הסגור.
